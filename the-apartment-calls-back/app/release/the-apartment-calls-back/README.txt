THE APARTMENT CALLS BACK — FULL EDITION

What is included
This folder contains the complete English game: the opening call, three recorded calls, three contradictions, and three endings.

How to play
1. Keep index.html, the css folder, and the js folder together.
2. Open index.html in a modern browser. No installation, account, or internet connection is needed after downloading.
3. Answer the opening call. Then select two items in the call log and press Compare. Use Hint if you get stuck.
4. Find all three contradictions to unlock the final decision. You can return to see the other endings.

Your puzzle progress is saved only in this browser on this device. Use Start over to clear it.

Content note: suspense and a missing person. No gore.
