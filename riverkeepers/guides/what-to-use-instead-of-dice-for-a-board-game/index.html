What to use instead of dice for a board game

For a game that needs ordinary six-sided dice, write 1 through 6 on six equal paper slips, fold and mix them, then draw one number. Return the slip and mix again before every draw, including the second draw of a two-dice roll, so repeated numbers and doubles remain possible.

Make an offline six-sided substitute

  1. Cut six equal-size slips from spare paper. Write one number on each: 1, 2, 3, 4, 5, and 6.
  2. Fold them alike so the numbers cannot be seen. Mix them in an opaque cup or bag.
  3. Draw one slip, read and record the result, put it back, and mix again.
  4. If the rule asks for two dice, repeat the draw for the second result. Keep the two results separate; do not add them unless the game's rules say to.

Replacing after every draw matters. If you leave the first slip out, the second result cannot match it, so a double becomes impossible. Equal slips and thorough mixing help each number have the same chance of being drawn.

A coin flip by itself has only two outcomes. A deck draw without replacement changes later results. Both need extra rules to behave like a six-sided die.

A concrete two-dice turn

In Riverkeepers' Past turns, one die sets a map row and the other adds Water. Suppose your first slip is 3 and your second is 5. You may choose row 3 for a legal build and use 5 for Water, or choose row 5 and use 3 for Water. For example, on an empty map, a Settlement at C3 is legal if you choose row 3; it is a riverside land cell, not river column D.

Put the slip back and mix before the second draw. If both draws are 2, the game treats them as doubles: you have no die-assignment choice, and after the usual build you draw again for a Past Event. The same replacement rule applies to that event draw. See the full game's rules and contents.

FAQ

How do I replace two dice with one set of paper slips?

Draw once, record the first number, return the slip, mix, and draw again. This gives two separate results and still allows doubles. Do not keep the first slip out while drawing the second.

Why must I put the slip back each time?

A die can show the same number on consecutive rolls. Returning the slip restores all six possible results for each draw; leaving it out changes the game's chances and rules out a double on that pair.

Can I use a phone instead?

Yes, if a dice tool can give separate six-sided results. Check its connection and privacy needs before relying on it; folded slips work without a device or internet.

Does this work for every board game die?

This six-slip method replaces an ordinary six-sided number die. Games with different-sided dice, special symbols, or custom faces need a substitute matching those outcomes. Follow that game's own instructions where provided.
